# SEO skills

These skills were vendored from [claude-seo](https://github.com/AgriciDaniel/claude-seo)
(MIT licensed, see each skill's `LICENSE.txt`) to give Claude Code SEO expertise
when working on this site: technical audits, schema markup, sitemaps, Core Web
Vitals, local SEO, backlinks, AI/GEO optimization, content briefs, and more.

Some skills reference an optional `claude-seo run <script>.py` CLI helper from
the upstream project that isn't bundled here — only the `SKILL.md` guidance
(checklists, frameworks, quality gates) was installed. Claude can still follow
that guidance manually with its own tools; the helper scripts and paid API
extensions (DataForSEO, Ahrefs, SE Ranking, etc.) can be added later from the
upstream repo if needed.
